# neural_optimization_course

Repository for the course on Neural Network Optimization.

## Deployment Health Score (free tool)

A Streamlit app that audits any `.pt` / `.pth` checkpoint and returns a
single deployment-readiness score covering precision, pruning, size, and
ONNX / TensorRT exportability. See [`deployment_visualizer/`](deployment_visualizer/)
for setup and run instructions.
